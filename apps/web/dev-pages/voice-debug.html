Amoji Voice Debug

On iOS, every audio path is gesture-gated: nothing below may produce sound (or even start an AudioContext) unless the tap that runs it IS a user gesture. So: press each button by hand, one at a time, and read the log. Also check the hardware silent switch — ON mutes all web audio and speechSynthesis on Safari, and no page can detect it. Voice matrix target locales: zh-HK (Cantonese), zh-CN, ja-JP, en-US.
