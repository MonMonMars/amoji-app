One page for accounts, search limits, and warnings. It talks directly to the Node API at the address below. The admin token stays in this tab's sessionStorage and is sent only in the Authorization header — never in the URL.

Running the API locally 
cd server/backend
$env:AMOJI_ADMIN_TOKEN = "a-long-random-token"
npm start
# listens on http://127.0.0.1:8787 by default

On GitHub Pages this page is served over HTTPS. The production API must also be HTTPS, otherwise the browser blocks the request. The default http://127.0.0.1:8787 is for local development only.

Search breaker

—

closed = normal search. soft = allow up to the cap and make the client show a long character line as a delay. hard = refuse API search. Window: 60 minutes. Every change is timestamped in the server's event log.

The API counts every allowed POST /api/search (the curated keyless list is never counted). The warnings block shows today's total and how much of the current window the shared search lane has used, and warns when it reaches the cap. The breaker is the server-side control for the optional API lane.
