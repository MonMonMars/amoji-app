# Premade sing & dance library

Short clips only (about 15–20 seconds, a few vocals shorter or ~45s).
Files are MP3 transcodes of the CC0 / public-domain ogg previews so
Safari and iPhone can decode them. Full-length masters are not shipped.

Asking to **sing** plays a `sing-f-*` or `sing-m-*` clip matching the
companion's gender (dialogue volume). Asking to **dance** plays a dance
track or instrumental bed (BGM volume).

Licenses are CC0-1.0 or public domain. No CC-BY and no commercial tracks.

## Add another clip

1. Drop a CC0 or public-domain MP3 in this folder.
2. Add a row to `PERFORMANCE_CLIPS` in `apps/web/lib/performance-clips.ts`
   (`kind: 'song'` needs `voice: 'female'` or `'male'`; dance and beds omit voice).
3. Add the same file to the table above.
